# 公开范围

公开仓库用于分享结构与规则，不保存真实连接凭据。

## 本次已处理

- 移除全部 123 条代理定义，包括节点服务器、端口、密码和私有节点名称。
- 移除家庭 WireGuard 段、密钥、对端和具体家庭网段，替换与家庭路由绑定的策略组。
- 移除 MITM 的证书包和证书密码。需要 MITM 时，在自己的设备本地生成、安装并信任自己的证书。
- 不保留订阅商名称、定制节点标签和含个人访问痕迹的手工例外。
- 未审核的 URL 留在本地覆盖文件；公开配置仅保留明确审核的公开来源。
- 移除第三方图标的运行时引用，减少未确认许可的素材依赖。

通用私网地址范围，例如用于跳过代理的 `192.168.0.0/16`，属于协议配置常量，不代表具体家庭地址。

## 必须留在仓库之外

原始配置、私密覆盖文件、恢复出的本地配置、订阅地址、节点清单、API 控制密钥、WireGuard/Tailscale 凭据、MITM 证书、抓包和运行日志，都应保存在仓库之外。

`.gitignore` 和检查脚本只是辅助。浏览器手工上传不会遵守 `.gitignore`，已经被 Git 跟踪的文件也不会因为新增忽略规则而消失。请只上传本仓库目录中的公开文件。

私有 GitHub 仓库、Secret Gist、Base64 编码和 GitHub Actions Secrets 都不用于存放本配置的节点凭据。编码不会改变敏感性；把完整运行配置生成到 Actions 产物或日志中仍可能造成泄露。

## 本地工具的边界

导出工具针对本次配置结构整理，不承诺能自动识别任意配置中的所有秘密。新增脚本、模块、访问令牌、自定义 DNS 路径或其他命名段时，仍需逐项检查。

本地恢复文件包含真实秘密，工具将其写到公开仓库之外，并设置为仅当前用户可读写。请不要打包、截图或上传该文件。

如果曾把真实凭据上传到公开位置，删除当前文件不足以撤回历史和他人副本。应先撤销相应订阅令牌、节点凭据或密钥，再清理历史。本次操作没有把原始文件上传到 GitHub。
