# Surge Modules

Personal app filters and utilities. Module URLs and independent scripts are hosted in this repository.

> **One-click install:** Select **Install in Surge** on an iPhone with Surge installed. The link uses Surge's official `surge:///install-module?url=...` scheme. If GitHub or a browser blocks the deep link, copy the **Raw** URL into Surge > Modules > Install from URL.
> **Requirements:** Some modules need Surge MITM and a trusted certificate. Do not enable overlapping filters for the same app.
> **Validation:** Offline validation does not guarantee compatibility with the latest app releases.

## Notes

- **Updated:** Last committed modification to the module file, verified against GitHub history on 2026-10-31.
- **Xiaohongshu:** The main module includes image, video and Live Photo watermark handling. Results depend on the app's response formats.
- **JD / NetEase Cloud Music / Tieba:** Some encrypted or binary data formats are not handled.
- **Tencent Video:** Do not enable `TencentVideo.sgmodule` and `TxvideoAD.sgmodule` together.
- **Meituan / Dianping:** Shared endpoints can result in conflicting rewrites.
- **Google CN Redirect:** Already included in the main profile; avoid duplicate installation.
- **After installation:** Check app launch, login, search, messaging, checkout, and payment. Disable filters that break normal behavior.
